MCP-toke transport layer module. Implements both stdio (Content-Length framed JSON-RPC over stdin/stdout) and SSE (Server-Sent Events over HTTP with /sse, /message, and /health endpoints plus CORS support) transports for the MCP server. Exports $sseevent type and startstdio, startsse, framemessage, readframedmessage, and formatsseevent functions. Depends on mcptoke.server, core.mcp.protocol, std.json, std.str, shared.log, std.io, and std.net.
