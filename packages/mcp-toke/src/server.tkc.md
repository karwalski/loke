MCP-toke JSON-RPC server module. Listens on a TCP port (default 11460; F3b.12 moved it off the privacy-filter sidecar's 11435) and handles initialize, tools/list, and tools/call MCP methods, dispatching tool calls to the tools module. Manages connection read/write lifecycle in an accept loop. Exports $serverconfig type and defaultconfig, handlerequest, dispatchrequest, handletoolscall, and start functions. A tools/call hands the tool the raw JSON of `arguments` (`jx.valueraw`; MK6.10). Depends on shared.types, core.mcp.protocol, mcptoke.tools, std.http, std.json, shared.jsonobj, std.str, shared.log, and std.net.
