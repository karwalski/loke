The `layer_metrics` MCP tool (F3b.10): the per-layer privacy metrics body of `GET /api/layermetrics` (core.audit.layermetricsreport) over a window (24h, 7d, 30d, all), from the store in the user's loke directory; an unknown window or an unopenable store is a tool error. Offered by mcptoke.server, not mcptoke.tools, so moke's in-process tool panel never opens loke's store. Aggregates only, never a detected value.
