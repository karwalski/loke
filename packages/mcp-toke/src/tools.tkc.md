MCP-toke tool definitions and handlers. Defines and implements five MCP-callable tools: anonymise (PII detection and anonymisation via the privacy pipeline), compress (JSON to TOON conversion), profile (JSON array schema profiling), decompress (TOON back to JSON), and analyse (sensitivity risk assessment). Exports alltools, handletool, sensitivitylabel, and safetosend functions plus per-tool definition and handler functions. Depends on shared.types, core.mcp.protocol, core.privacy.pipeline, core.optimiser.toon, core.optimiser.profiler, std.json, std.str, and shared.log.
