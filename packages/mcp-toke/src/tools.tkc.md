MCP-toke tool definitions and handlers. Defines and implements five MCP-callable tools: anonymise (PII detection and anonymisation via the privacy pipeline; answers the anonymised text and counts, never the original, and refuses a run no layer scanned; MK6.10), compress (JSON to TOON conversion, with measured character savings, or a named refusal; MK6.7), profile (JSON array schema profiling through `profiler.profilejson`, or a named refusal; MK6.10), decompress (TOON back to JSON, or a named refusal), and analyse (sensitivity risk assessment; each entity as type and offsets, never its value; MK6.10). Exports alltools, handletool, sensitivitylabel, and safetosend functions plus per-tool definition and handler functions. Depends on shared.types, core.mcp.protocol, core.privacy.pipeline, core.optimiser.toon, core.optimiser.profiler, std.json, std.str, shared.log and shared.jsonobj.
