Model lifecycle management commands. Provides update (checks for and pulls newer model versions via core.installer.updater) and uninstall (removes models or Ollama itself via core.installer.uninstall) with user confirmation prompts. Exports runupdate, rununinstallmodel, and rununinstallollama functions. Depends on shared.types, std.str, cli.output, shared.log, storage.db, core.installer.updater, and core.installer.uninstall.
