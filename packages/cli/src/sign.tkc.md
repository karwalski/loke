Code signing and notarisation for loke binaries. Handles macOS codesign with entitlements, notarytool submission with Apple ID credentials, stapling, and verification. Also supports Windows signtool signing with certificate and timestamp. Generates a default entitlements plist allowing network client access. Exports $signconfig and $signresult types plus signmacos, notarizemacos, verifymacos, signwindows, and defaultentitlements functions. Depends on std.fs, std.str, and std.shell.
