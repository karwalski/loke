Boot sequence for the loke CLI daemon. Loads and validates configuration from a TOML file, requiring ollama_url and data_dir to be non-empty, logs a boot summary with port, data directory, and provider details, and provides a shutdown sequence for cleanup. Exports $bootstage and $bootresult types plus bootsequence, shutdownsequence, and logbootsummary functions. Depends on shared.types, shared.config, shared.log, and std.str.
