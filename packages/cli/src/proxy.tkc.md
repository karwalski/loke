Privacy proxy server that intercepts LLM traffic from coding tools (Claude Code, Codex, Gemini CLI). Listens on a local port, parses incoming JSON requests, runs prompts through the privacy pipeline to anonymise PII, forwards the sanitised request to the upstream LLM via the dispatcher, restores placeholders in the response, and tracks per-session statistics. Supports --port, --verbose, and --dry-run options. Exports $proxyconfig and $proxysession types plus defaultconfig, parseopts, handlerequest, start, and usage functions. Depends on shared.types, shared.log, cli.output, std.net, std.http, std.json, core.privacy.pipeline, providers.dispatcher, shared.config, and std.str.
