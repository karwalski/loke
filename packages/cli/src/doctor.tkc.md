Diagnostic health checker that probes Ollama, Presidio, and LLMLingua endpoints for connectivity and verifies the ~/.loke/ data directory and config.toml file exist. Prints a pass/fail report with suggested fixes for each failing check. Exports the $check type and the checkollama, checkpresidio, checkllmlingua, checkdatadir, checkconfig, runall, formatreport, and run functions. Depends on shared.types, cli.output, std.http, std.str, shared.log, and std.file.
