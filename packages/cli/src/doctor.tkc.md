Diagnostic health checker that probes Ollama, Presidio, and LLMLingua endpoints for connectivity and verifies the ~/.loke/ data directory and config.toml file exist. Prints a pass/fail report with suggested fixes for each failing check. Each service check goes through `checkservice(name;baseurl;path;expect;fix)` (VM1.6h): a URL off this machine is not checked, then a shared.reachability probe ("not reachable"), then a GET whose body must be non-empty ("no answer") and, for Ollama, carry a `models` array ("answered, but not as Ollama does"). The one-argument GET exposes no status code. `checkollamaat`, `checkpresidioat` and `checkllmlinguaat` take the base URL; the argument-less forms use the default ports. Exports the $check type and the checkservice, checkollamaat, checkpresidioat, checkllmlinguaat, checkollama, checkpresidio, checkllmlingua, checkdatadir, checkconfig, runall, formatreport, and run functions. Depends on shared.types, cli.output, std.http, std.str, shared.log, std.file, and shared.reachability.
