CLI interface for compliance reporting with generate and templates subcommands. Generates reports using core.governance.reportengine with configurable template (compliance_summary, pii_detection_log, routing_decisions, policy_changes, cost_savings), date range, and output format, then renders them via core.governance.reportexport. Exports run, printusage, rungenerate, and runtemplates functions. Depends on core.governance.reportengine, core.governance.reportexport, std.str, shared.log, and loke.platform.i18n.translator.
