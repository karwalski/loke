`loke report generate` and `loke report templates` (GA5.31), dispatched from `cli.main`. `handle` takes the command kind from `cli.commands.parsereport` and argv: `templates` prints the engine's template list and what G4.4 names that is not built; `generate` checks the template with `core.governance.reportengine.knowntemplate`, opens the store at the configured data directory, builds the filter from `cli.commands.reportstart/reportend/reporttemplate/reportformat`, runs `reportengine.generate` and prints `core.governance.reportexport.export` to stdout. Exits 1 for an unknown template, an unopenable store, or a report the engine could not produce (bad window or failed query). A report reads `audit_log` only. Depends on `shared.config`, `core.governance.reportengine`, `core.governance.reportexport`, `core.storage.db`, `cli.commands`, `cli.output` and `std.str`.
