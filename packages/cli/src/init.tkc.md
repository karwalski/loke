First-run initialisation command that creates ~/.loke/ config and bin directories, detects the user's shell (zsh/bash), appends LOKE_HOME and PATH exports to the shell profile if not already present, and verifies Ollama is reachable (`ollamarunning(baseurl)`: a GET /api/tags through shared.reachability.localget whose body carries a `models` array; VM1.6h). Reports setup results with tick/cross indicators. Exports $initresult type and run, usage, detectshell, profilepath, and lokeshellsnippet functions. Depends on shared.types, cli.output, shared.reachability, std.file, std.str, and std.env.
