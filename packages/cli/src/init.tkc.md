First-run initialisation command that creates ~/.loke/ config and bin directories, detects the user's shell (zsh/bash), appends LOKE_HOME and PATH exports to the shell profile if not already present, and verifies Ollama is reachable. Reports setup results with tick/cross indicators. Exports $initresult type and run, usage, detectshell, profilepath, and lokeshellsnippet functions. Depends on shared.types, shared.log, cli.output, std.file, std.str, std.http, and std.env.
