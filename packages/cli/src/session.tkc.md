Named session management backed by SQLite. Supports creating, listing, switching, and closing sessions via list/new/switch/close subcommands. Tracks per-session request counts and timestamps, and provides formatted table output of session state. Exports the $session type and ensuretable, newsession, listsessions, getactive, switchto, closesession, recordrequest, formatsessions, and run functions. Depends on shared.types, shared.log, cli.output, storage.db, and std.str.
