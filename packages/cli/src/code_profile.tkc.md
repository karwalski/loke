Source code secret profiler that scans lines for PEM keys, API keys (OpenAI sk-, GitHub ghp_, Slack xoxb-, AWS AKIA), environment secrets with long values, and connection strings with embedded credentials. Produces a redacted copy of the source with all secrets replaced by placeholders. Exports $codefinding and $profileresult types plus checkpem, checkapikey, checkenvsecret, checkconnstring, redactline, profile, collectkinds, summarise, and issafe functions. Depends on std.str and std.arr.
