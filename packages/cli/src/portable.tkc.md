Generates portable install and uninstall shell scripts for the loke binary. The install script copies the binary to the target directory, creates ~/.loke data directories, and appends PATH entries to the shell profile. The uninstall script removes the binary, optionally deletes ~/.loke, and cleans up profile entries. Exports verifybinary, defaultinstalldir, installscript, uninstallscript, and writescript functions. Depends on std.fs and std.str.
