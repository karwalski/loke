Verbose pipeline output formatter for debugging. Renders detailed pipeline run information including per-stage status symbols, durations, error messages, and key-value detail pairs. Provides a summary line with stage completion counts and total duration. Exports printrun, printevent, and printsummary functions. Depends on core.pipeline.types, core.pipeline.emitter, std.str, shared.log, and loke.platform.i18n.translator.
