Runtime health monitoring module that probes Ollama, Presidio (NER), and LLMLingua subsystems via HTTP with timeouts, classifying each as ok, degraded, or down using the $healthstatus sum type. Produces a $healthreport with overall status and per-subsystem details, and formats a human-readable diagnostic output. Exports $healthstatus, $subsystemhealth, and $healthreport types plus checkall and formatreport functions. Depends on shared.types, std.http, std.str, and shared.log.
