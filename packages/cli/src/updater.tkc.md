Self-update mechanism for the loke binary. Checks GitHub releases for newer versions with platform-specific asset matching, downloads the update, verifies SHA-256 checksums, applies the update with a backup and rollback on failure, and implements a 24-hour snooze to avoid repeated prompts. Exports $updateinfo and $updateresult types plus check, download, verifychecksum, apply, promptupdate, and versiongt functions. Depends on std.fs, std.str, std.http, and std.shell.
