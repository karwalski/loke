Interactive and non-interactive installer for Ollama and local models. Detects hardware (chip, RAM, disk), recommends a model size based on available memory, downloads and installs Ollama if needed, pulls the recommended model, and verifies it with a test prompt. Supports --yes (non-interactive), --model, --skip-model, --ollama-url, and --install-dir flags. Exports $installerflags, $hwinfo, $modelrec, and $verifyresult types plus run, runinteractive, runnoninteractive, runskipmodel, and recommendmodel functions. Depends on std.str, cli.output, shared.log, std.http, std.sys, std.process, std.file, and std.env.
