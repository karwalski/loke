Proxy environment variable configuration module. Maps tool names (claude-code, openai, cursor) to their respective base URL environment variables (ANTHROPIC_BASE_URL, OPENAI_BASE_URL, OPENAI_API_BASE) and injects export lines into the user's shell profile, skipping variables that already exist. Exports the $proxyenv type and envvarsfortool, injecttoprofile, and run functions. Depends on shared.types, shared.log, cli.output, std.file, and std.str.
