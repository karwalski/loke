`loke privacy evaluate` (F3b.9). Builds the pipeline configuration `loke ask` uses (Presidio and Ollama URLs from config.toml, with its privacy-filter, consensus and `[[privacy.layers]]` settings) and prints `core.privacy.comparison`'s report for a text, or its labelled per-layer tp/fp/fn report for a corpus-format JSONL file (`--file`). Exits 1 when no layer scanned, the layer config cannot be applied, or the file holds no readable text. Depends on `std.str`, `std.file`, `cli.output`, `core.privacy.pipeline`, `core.privacy.comparison`.
