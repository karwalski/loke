CLI ask command handler. Parses ask-specific options (--model, --dry-run, --stream, --system, --tolerance), runs the user prompt through the privacy pipeline for PII anonymisation, routes it to an appropriate LLM via the router and dispatcher, and prints the response with pipeline stage indicators and audit logging. Exports the $askopts type and the parseopts, defaultopts, run, and usage functions. Depends on shared.types, shared.log, shared.config, cli.output, core.privacy.pipeline, providers.dispatcher, core.router.router, core.governance.gateway, and std.str.
