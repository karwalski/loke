Local model installer page. Detects system hardware (RAM, chip, platform, disk) and Ollama status, recommends an appropriately sized Qwen 2.5 model variant based on available memory, and renders the installer.tkt template with hardware and model data as JSON. Exports get, recommendmodel, hardwaresummaryjson, allmodelsjson, and type $modelrec. Depends on std.http, std.json, std.str, std.sys, ooke.template, browser.extensions.core, core.models.ollama, core.models.hardware, and shared.log.
