The user's answer to a request `/api/pipeline` held for approval (GA5.26). `POST {"approval_id":"...","decision":"approve"|"decline"}` decides a pending, unexpired approval once through `core.governance.approvalgate`: 200 with the action taken, 404 for an unknown id, 409 when it was already decided or has expired, 400 for a missing id or an unknown decision, 503 when the store cannot be opened. Approving sends nothing; the approval page then re-sends the request with the id. Was a stub returning a constant `{"ok":true,"action":"approved"}`. Exports `approvejson`, `failurejson`, `actionof`, `apply`, `requestbody`, `openstore`, `respond`, `post`.
