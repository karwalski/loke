Settings UI API for registered token-classification privacy models (F3b.7). GET lists ~/.loke/privacy-models.json as the pipeline reads it; POST registers one through core.privacy.modelregistry.register, the path loke privacy add-model takes (re-registering an id replaces it), or with {"remove":"<id>"} removes one through modelregistry.unregister, the path loke privacy remove-model takes. Bodies come from core.privacy.layerview.
