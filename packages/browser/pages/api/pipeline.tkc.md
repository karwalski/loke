Privacy pipeline API endpoint with full core engine integration. Exports get and post handlers. The post handler: (1) validates input text, (2) checks the governance kill switch via core.governance.killswitch.isengaged() and returns 403 if engaged, (3) runs the full core privacy pipeline (regex + NER + Presidio detection, deduplication, anonymisation, guardian prompt injection) via core.privacy.pipeline.run(), (4) evaluates governance policy via core.governance.policy.evaluate() for risk classification, (5) retrieves API keys from OS keychain via core.storage.keychain.getapikey() with settings.json fallback, (6) routes the anonymised text to Anthropic or local Ollama, (7) restores placeholders in the LLM response via core.privacy.placeholder.restore(), and (8) logs the request to the tamper-proof audit trail via core.storage.audit.logevent(). Response includes moke-compatible fields (anthropic_raw, provider, model) plus privacy metadata (entities_found, sensitivity, request_id, pipeline_ms, risk_tier, policy_warning). Also exports sensitivitylabel and parsetolerance helpers. Depends on std.http, std.str, std.json, std.file, shared.log, shared.types, core.privacy.pipeline, core.privacy.placeholder, core.governance.killswitch, core.storage.audit, core.governance.policy, core.storage.keychain, and core.storage.db.
