Settings management API endpoint. Exports get and post handlers. On POST, API keys (anthropic_api_key, openai_api_key) are stored in the OS keychain via core.storage.keychain.setapikey() and removed from the JSON file. Non-secret settings are persisted to ~/.loke/settings.json. On GET, keys are retrieved from the keychain first, falling back to JSON for migration from plaintext storage. Keys are masked for display (first 4 chars + "****"). Depends on std.http, std.str, std.json, std.file, and core.storage.keychain.
