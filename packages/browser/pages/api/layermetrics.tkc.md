Per-layer privacy metrics API (F3b.10). Exports get, which answers the aggregates of privacy_layer_metrics (by layer per day, agreement rate, by entity type, latency percentiles) over a window, or recorded false when no request in it recorded any; an unknown window is 400. metricsjson and metricsjsonfor are the testable body, built by core.audit.layermetricsreport, which the `layer_metrics` MCP tool answers with too. Origin-guarded.
