HTTP route registry for the browser UI. Exports wrapper handler functions for every API and page endpoint, and a registerall function that binds all GET/POST routes (e.g. /api/health, /api/models, /approve, /chat, /pipeline, /setup, /sysmon) to the std.http router and returns the list of registered paths. Depends on std.http and all page/API handler modules (page.api.approve, browser.pages.api.health, browser.pages.api.models, browser.pages.api.pipeline, page.api.privacy, page.api.savings, browser.pages.api.settings, page.api.tabs, page.approve, page.chat, page.index, page.installer, page.pipeline, page.privacy, page.savings, page.setup, page.sysmon, page.tabs).
