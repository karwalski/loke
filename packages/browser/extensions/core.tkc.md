Core extension bridge that initialises loke's engine subsystems for the browser UI. Loads configuration from ~/.loke/config.toml, sets up the privacy pipeline, request router, governance gateway, provider dispatcher, and API keys, returning them as a $corestate struct. Also exports accessor stubs (getconfig, getpipelineconfig, getrouter, getgateway, getdispatcher, getauditstore, getpreference, setapikey, setpreference, gettabstore, settabstore) and types $corestate and $lokecfgstate. Depends on shared.config, shared.log, core.privacy.pipeline, core.router.router, std.str, core.governance.gateway, and core.providers.dispatcher.
