Sidebar navigation component. Manages a tree-structured navigation state with ordered items, badges, icons, active-page tracking, compact mode, and nested children. Provides keyboard navigation (arrow keys, Home/End) via client-side JavaScript. Exports types $navitem and $navstate, and functions newstate, register, unregister, setactive, togglecompact, itemcount, sortbyorder, isactive, render, rendericon, renderbadge, script, and styles. Depends on std.str.
