HTTP route registry (src variant) for the browser UI. Exports wrapper handler functions for every API and page endpoint and a registerall function that binds all GET/POST routes to the std.http router, returning the list of registered paths. Includes additional POST handlers for /approve, /privacy, and /setup compared to the root _handlers module. Depends on std.http and all page/API handler modules (page.api.approve, page.api.health, page.api.models, page.api.pipeline, page.api.privacy, page.api.savings, page.api.settings, page.api.tabs, page.approve, page.chat, page.index, page.installer, page.pipeline, page.privacy, page.savings, page.setup, page.sysmon, page.tabs).
