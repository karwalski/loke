Form validation component. Provides both server-side and client-side validation with rule types including required, min_length, max_length, pattern, and email. Exports types $ruletype, $rule, $fieldresult, $formresult, and functions required, minlength, maxlength, pattern, email, validaterule, validatefield, and script (which emits the client-side JavaScript validation logic exposing window.lokeForm). Depends on std.str.
