Configuration loading for loke. Defines the $lokeconfig struct with server port, data directory, log level, provider URLs (Ollama, Presidio, LLMLingua), and the privacy-filter sidecar's operating point `pfthreshold`, read from `privacy.privacy_filter_threshold` as text: a TOML string, an integer, or an unquoted float read from its line of the file because std.toml has no float accessor (F3b.16); empty (the default) means the sidecar's own default governs (AD1.4). F3b.16: `privacyerror(text)` says why `privacy.consensus_threshold` or `privacy.privacy_filter_threshold` is set and unusable (out of 0..1, not a number, wrong type, unreadable form, or a file that is not TOML); core.privacy.layerconfig.resolve refuses the config with it. Loads and parses TOML configuration from a file path with sensible defaults for all fields. Exports the $lokeconfig type and defaultconfig and loadconfig functions. Depends on std.file and shared.types. F5.3: routingstrategy, routingpreferlocal and routingfallbacktocloud come from the [routing] table (strategy, prefer_local, fallback_to_cloud), and default to local-first, true and false.
