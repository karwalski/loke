Configuration loading for loke. Defines the $lokeconfig struct with server port, data directory, log level, provider URLs (Ollama, Presidio, LLMLingua), and the privacy-filter sidecar's operating point `pfthreshold`, read from `privacy.privacy_filter_threshold` as a TOML string because std.toml has no float accessor at this toolchain; empty (the default) means the sidecar's own default governs (AD1.4). Loads and parses TOML configuration from a file path with sensible defaults for all fields. Exports the $lokeconfig type and defaultconfig and loadconfig functions. Depends on std.file and shared.types.
