Cross-origin refusal for state-changing endpoints (GA2.6). CORS decides whether a page may read a response. It does not stop a simple POST being sent, so a hostile page could drive `/api/pipeline` and `/api/settings`. A request carrying an Origin header must come from http on a loopback host. A request with no Origin (curl, the CLI, tests) is allowed. Exports `isloopbackorigin`, `originrefused`, `crossoriginrefused` and `refuse`. Depends on `std.http` and `std.str`.
