Core type definitions shared across loke. Defines sum types for sensitivity levels (public/internal/confidential/restricted), providers (anthropic/openai/google/mistral/openrouter/ollama/local), task types, model tiers, latency tolerance, risk tiers, and policy decisions. Defines record types for PII entities, detection results, model specs, routing decisions, pipeline results, and the $lokeerr tagged union for error handling. Also provides string and numeric utility wrappers. Depends on std.str.
