ML API endpoint providing k-means clustering, z-score and IQR anomaly detection, correlation matrix computation, and ML proposal generation from dataset schemas. Each kind returns from its own branch rather than accumulating a response body. JSON string arrays and the 2-D rows array are read through std.json's typed json.arr plus shared.jsonobj, because json.getstrarray, json.parse2dstrarray, json.getobj and json.encodestrarray exist in neither the interface nor the runtime and json.getstr segfaults on raw text. Numeric options are parsed with str.toint / str.tofloat, whose error arms supply the defaults, because str.isnumeric and str.isfloat do not exist. Depends on std.http, std.json, std.str, std.fmt, shared.jsonobj, moke.ml.engine, and moke.ml.proposal. ooke.handlers does not route this module.
