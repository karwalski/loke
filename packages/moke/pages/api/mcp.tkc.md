MCP API endpoint module providing tool panel, broker status, and memory demo endpoints. Depends on std.http, std.json, std.str, std.time, shared.jsonobj, moke.mcp.toolpanel, moke.mcp.brokerstatus, and moke.mcp.memorydemo. The three panels are module-level mutable state, declared between the imports and the first function; the broker panel is seeded with its demo servers in its initialiser, since the initstate() function that used to do it was never called and declared its state as locals. Tool arguments are read with shared.jsonobj.valueraw, because json.getraw does not exist and std.json cannot read a nested value.
