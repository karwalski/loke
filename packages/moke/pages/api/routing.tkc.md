Routing API endpoint that builds a routing decision, tier visualisation, and cost comparison for a given prompt and sensitivity level. Note that the decision does not depend on the prompt: the intent is hard-coded to data_analysis, the tier to "interactive" and the hardware summary to an Apple M-series string, and both `prompt` and `tolerance` are read from the body and unused — only sensitivity and model_id reach the answer. Depends on std.http, std.json, std.str, std.time, shared.jsonobj, moke.routingexplainer, moke.tiervisualiser, and moke.costcomparison; the moke.companionsimulator import was unused and is gone.
