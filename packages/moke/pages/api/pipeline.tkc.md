Pipeline API endpoint that applies schema-first hooks, forwards prompts to the loke pipeline upstream at port 11430, and appends console log metadata to the response. GET answers a readiness probe; POST does the work. The upstream call goes through http.post(url;body) — two arguments, not three — and an empty response body is the failure signal, because std.http exposes no way to read a status code and http.ok has no runtime symbol. Depends on std.http, std.json, std.str, std.time, shared.jsonobj, moke.hooks, and moke.consolelog; the moke.compute import was unused and is gone.
