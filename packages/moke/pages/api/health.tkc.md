API endpoint that proxies health checks to the loke core service. Attempts to reach loke at 127.0.0.1:11430 and returns either the upstream response or a 503 fallback with error details. Depends on std.http, std.str, and shared.log — the two log calls pass (message; module; requestid), which is shared.log's three-argument shape; std.log.info takes two.
