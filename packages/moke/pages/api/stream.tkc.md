Streaming API endpoint that processes prompts through schema extraction and anonymisation stages, then forwards to the loke pipeline with stream=true. Nothing actually streams: the upstream response is fetched whole and returned in one JSON body, with the stream session's stage events alongside it. The upstream field is null rather than empty when the pipeline gives nothing back, so the response stays parseable. Depends on std.http, std.json, std.str, shared.jsonobj, moke.hooks, and moke.streaming; the moke.routingexplainer, moke.costcomparison and moke.consolelog imports were unused and are gone.
