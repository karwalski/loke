API endpoint for user feedback submission in moke. Accepts thumbs up/down ratings with optional context (feature area, request ID, model, dataset, comment), stores the rating in loke's feedback store through moke.feedbackrecord (the `feedback` table of `$HOME/.loke/loke.db`, written by core.feedback.store), and answers `{"ok":true,"stored":true,"id":...}` with the stored row's id, or 503 when it could not be stored (LS1.4a: the fields were read and discarded and nothing was persisted). A missing or unknown rating is 400. Depends on std.http, std.json, std.str, shared.jsonobj and moke.feedbackrecord.
