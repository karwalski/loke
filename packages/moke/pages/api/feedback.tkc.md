API endpoint for user feedback submission in moke. Accepts thumbs up/down ratings with optional context (feature area, request ID, model, dataset, comment) and returns a generated feedback ID. Nothing is persisted: feature_area, model_id, dataset and comment are read from the body and discarded, and moke.feedback offers no store function. Depends on std.http, std.json, std.str, std.time, and shared.jsonobj.
