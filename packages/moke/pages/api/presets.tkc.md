GET `/api/presets` (RG1.9): the built-in policy presets as JSON, derived at run time from `core.policy.presets.registry` through `core.policy.presets.catalog`. Each preset carries its id, name, jurisdiction, description, source, default classification, approval threshold, cross-border flag, blocked entity types, per-status rule counts and its rules, each with the status its description declares (evaluable, documentation, unimplemented or unclassified; never enforced). The body also states that presets are not enforced on the request path. `bodyfor(views)` renders any list of views so a test can add a preset or reclassify a rule and see the body change; `body()` renders the real registry and `get` serves it. Depends on std.http and core.policy.presets.catalog. The governance page (`templates/governance.tkt`) is its only consumer.
