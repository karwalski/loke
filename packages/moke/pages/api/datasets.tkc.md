API endpoint for dataset detail retrieval in moke. Accepts a POST with dataset ID, looks it up in the registry, profiles its columns for PII detection, and returns full metadata including headers, rows, and column statistics as JSON. The registry returns an untyped i64, so the body is a function taking ds:$dataset — a typed parameter is what establishes the struct type for field access. Depends on std.http, std.json, std.str, shared.jsonobj, moke.data.registry, moke.profiler, and moke.compute (for the $dataset type).
