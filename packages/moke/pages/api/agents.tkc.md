API endpoint for the moke agents panel. Manages two built-in agents (data quality scanner, schema change detector) as module-level state, seeded in its initialiser rather than by an init() function nothing called. Provides GET for panel state, POST /scan for on-demand data quality scanning, POST /schema for schema diff detection, and GET /diary for agent run history. Timestamps are real ISO-8601 values from std.time, not the literal string "now" the earlier version passed (MK21.13). JSON string and 2-D string arrays are read through std.json's typed json.arr plus shared.jsonobj, because json.getstrarray and json.parse2dstrarray do not exist and json.getstr segfaults on raw text. Depends on std.http, std.json, std.str, std.time, shared.jsonobj, and moke.agents.{qualityscanner,schemadetector,status} plus moke.hooks. Neither glastreport nor glastdiff is served by any route yet.
