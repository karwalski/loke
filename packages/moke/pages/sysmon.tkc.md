System monitoring API endpoint for moke. Returns JSON with CPU count, RAM usage, and per-process stats for Ollama and loke by parsing ps output and sysctl values. Depends on std.http, std.str, and std.process. cpu_percent, ram_percent, used_ram_mb, free_ram_mb, every pid and slm_active are hard-coded zeros and falses in the response — only cpu_count, total_ram_mb and the two per-process cpu/ram figures are measured.
