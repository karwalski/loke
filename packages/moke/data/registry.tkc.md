Looks a dataset up by id in `static/data/manifest.json`, the one catalogue the browser reads too (MK19.1), and loads the CSV file the entry points at. The id is matched against the manifest and never used as a path. Replaces a hand-written catalogue and dispatch over four modules reading `data/csv`, which held different tables from the UI under the same ids. Exports `getdataset`. Depends on `std.str`, `std.json`, `std.file`, `moke.data.loader` and `moke.compute`.
