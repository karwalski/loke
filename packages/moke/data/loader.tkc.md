Reads a demo dataset from moke's one dataset store, `static/data` (MK21.16, MK19.1): the same CSV files the browser fetches. The directory is `MOKE_DATA_DIR`, else `static/data`, else `packages/moke/static/data`. A dataset that cannot be read returns empty and is logged. Exports `datadir`, `emptydataset` and `loaddataset` (a path relative to the store). Depends on `std.str`, `std.env`, `std.file`, `shared.log`, `moke.compute` and `moke.upload`.
