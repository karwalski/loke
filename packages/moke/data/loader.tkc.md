Loads moke's demo datasets from CSV files under `data/csv` (MK21.16). They were literal arrays compiled into four modules, which crossed toke's silent IR-truncation limit (T-35), so moke could not link. The directory is `MOKE_DATA_DIR`, else `data/csv`, else `packages/moke/data/csv`. A dataset that cannot be read returns empty and is logged. Exports `datadir`, `emptydataset` and `loaddataset`. Depends on `std.str`, `std.env`, `std.file`, `shared.log`, `moke.compute` and `moke.upload`.
