Stores a rating from moke's `/api/feedback` in loke's own feedback store (LS1.4a): `save(rating;area;requestid;modelid;dataset;comment)` opens `$HOME/.loke/loke.db` through `core.storage.db.openstore`, ensures the `feedback` table and writes the row through `core.feedback.store.save`, answering the stored id, or "" when the store could not be opened or written. There is no second store. Maps moke's wire names onto the store's types (`ratingfor`, `areafor`: an unknown area is kept as `Other: <name>`); moke's `dataset` goes in `use_case`, `risk_level` is empty, and the comment is stored as typed, as core.feedback.store stores every comment (nothing scans feedback text; LS1.4c). Does not import moke.feedback, whose `$feedbackentry` would collide with core.feedback.types'. Depends on std.str, std.os, core.storage.db, core.feedback.store, core.feedback.types.
