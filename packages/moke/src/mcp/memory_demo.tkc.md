Interactive memory palace MCP tool demonstration module. Invokes memory tools (search, store, status, facts, context, diary_write) through the MCP memory server, records invocation history with result previews, and serialises state to JSON. Depends on core.memory.mcpserver, core.mcp.protocol and shared.utf8. The result preview is at most 200 bytes plus `...`, cut through `shared.utf8.prefix` so a multi-byte character is never split (F10.50).
