Routing explainer module that builds structured routing decisions capturing intent classification, sensitivity level, latency tolerance, model selection, provider, cost estimate, and tier assignment. Provides immutable-style update functions (withintent, withsensitivity, withtolerance, withselection) and JSON serialisation. withtolerance (LS1.4a) sets the request's latency tolerance, which nothing set before, so every explanation said instant. Depends on std.str and shared.jsonobj.
