Console logging module that records pipeline stage events (schema extract, anonymise, LLM call, response, etc.) with timestamps and duration, providing formatted text output and JSON serialisation. Each entry also carries a typed `$disclosure` record (DA1.4, spec §6.2 S1), which `tojson` emits as JSON numbers, booleans and strings, with `null` for anything the stage did not measure. `append` records all nulls; `appendwith` takes a record; `withfieldcount` and `withentities` set the two fields moke measures today. Depends on std.str, std.time and shared.jsonobj. Tested by packages/moke/tests/test_console_log_disclosure.tk.
