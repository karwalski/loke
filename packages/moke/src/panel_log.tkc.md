MK6.6 — the MCP and agents panels' history as files every pre-forked moke worker shares. `append(name;line)` adds one newline-free line to `$HOME/.loke/moke/<name>.log` (O_APPEND, one write per line); `lines(name)` reads every non-empty line back, oldest first, and an absent file is an empty history; `last(all;n)` keeps the most recent n. Callers write content-free records only: `moke.mcp.toolpanel.historyjson` and `moke.mcp.memorydemo.historyjson` drop arguments, results and errors, and the agents' run lines carry an index, ids, times, a finding count and a summary. The files are not trimmed. Depends on `std.str`, `std.file`, `std.os`.
