Local compute engine implementing dataset operations: count, sum, avg, min, max, group, timeseries, top-n, distribution, correlate, percentile, count-by, latest, distinct, and join. All computations run locally without sending data externally. Depends on std.str, std.log and shared.utf8. A timeseries groups a date cell by its first 10 bytes only when those bytes are a numeric date (ASCII, cut through `shared.utf8.prefix`); any other cell, such as `2026年10月7日`, is kept whole, so a label is never split inside a character and two days are never merged under a shared prefix (F10.50).
