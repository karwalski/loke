Pipeline hooks module implementing the schema-first protocol: detects raw tabular data in prompts, extracts column profiles (type inference, null/unique counts, sample values, numeric stats), and replaces raw data with a TOON-compressed schema. Also provides extensible before/after anonymisation hook registries and a rule evaluation framework including raw-data-guard blocking. Depends on std.string, std.log, and core.extensions.pipelinehooks.
