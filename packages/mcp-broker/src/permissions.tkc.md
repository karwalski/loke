MCP broker permissions module. Loads per-server tool allow/deny lists, rate limits, and privacy requirements from TOML configuration. Checks tool-level permissions at call time against allowed and denied tool lists, and applies permission state to server registry entries. Exports $serverpermission and $permissionconfig types plus checktoolpermission, loadfromtoml, parsetomlpermissions, applypermissions, findpermission, and formatpermissions functions. Depends on shared.types, mcpbroker.registry, std.json, std.str, shared.log, and std.fs.
