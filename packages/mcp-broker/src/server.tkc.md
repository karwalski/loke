MCP broker HTTP server module. Listens for JSON-RPC requests on a configurable port, dispatches initialize, tools/list, and tools/call methods to the aggregator and proxy respectively, and manages the TCP connection accept loop. Exports the $brokerconfig type and defaultport, handlerequest, and start functions. Depends on shared.types, std.net, mcp.protocol, std.json, shared.log, mcpbroker.registry, mcpbroker.aggregator, mcpbroker.proxy, and std.str.
