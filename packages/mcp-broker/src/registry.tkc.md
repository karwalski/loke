MCP server registry module. Maintains a list of upstream MCP server entries with host, port, tool-name prefix, and health status. Provides registration, tool-name-to-server lookup by prefix matching, HTTP health checking, default server definitions (mcp-toke on 11435, mcp-memory on 11437), and formatted table display. Exports $serverentry and $brokerregistry types plus newregistry, register, findfortool, defaultservers, healthcheck, and formatregistry functions. Depends on shared.types, shared.log, std.http, and std.str.
