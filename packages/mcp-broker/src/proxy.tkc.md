MCP broker proxy module. Routes tools/call requests to the appropriate upstream MCP server by matching tool name prefixes, applying privacy pipeline anonymisation before sending and restoration on the response. Returns a $proxyresult indicating success, upstream server, and whether privacy was applied. Exports $proxyresult type and proxycall and stripprefix functions. Depends on shared.types, mcp.protocol, std.http, std.json, shared.log, mcpbroker.registry, core.privacy.pipeline, and std.str.
