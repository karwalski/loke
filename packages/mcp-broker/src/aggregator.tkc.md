MCP tool aggregator module. Fetches tool lists from all healthy registered upstream MCP servers via HTTP, prefixes tool names with server-specific prefixes to avoid collisions, and builds a combined tools/list JSON-RPC response. Exports fetchtools, aggregateall, and toolslistresponse functions. Depends on shared.types, mcp.protocol, std.http, std.json, shared.log, mcpbroker.registry, and std.str.
