OpenAI API provider client. Sends chat completion requests to the OpenAI API with Bearer token auth, parses streamed/non-streamed responses, extracts token usage, and calculates cost based on model-specific pricing tiers. Depends on shared.types, core.providers.types, std.http, std.json, std.str, and shared.log. LS1.1j added completeplain and openaiparseplain, returning a plain $completionresponse; complete, openaiparseraw and openaiparseobj are kept and delegate.
