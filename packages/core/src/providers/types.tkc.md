Shared type definitions for the provider layer: chat message, completion request, completion response, and provider config structs. Also provides convenience constructors for user, assistant, and system messages. Depends on shared.types. LS1.1j added the shared completion sentinel: nocompletion (empty modelid, reason carried in finishreason), the iscompletion predicate and completionerror. Every provider's completeplain and the dispatcher's trydispatch family answer with these.
