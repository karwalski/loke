Ollama LLM provider adapter. Wraps the core.models.ollama client to implement the provider interface, sending chat completion requests to a local Ollama instance and returning standardised completion responses. Supports health checking to determine if the Ollama backend is reachable and running. Exports new, complete, and isavailable. Depends on shared.types, core.providers.types, core.models.ollama, std.str, and shared.log.
