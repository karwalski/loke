Ollama LLM provider adapter. Wraps the core.models.ollama client to implement the provider interface, sending chat completion requests to a local Ollama instance and returning standardised completion responses. Supports health checking to determine if the Ollama backend is reachable and running. Exports new, complete, and isavailable. Depends on shared.types, core.providers.types, core.models.ollama, std.str, and shared.log. LS1.1j added completeplain, returning a plain $completionresponse; complete is kept and delegates. complete previously matched ollama.sendchat's result with the $lokeerr arm first, so under T-18 every ollama and every local dispatch reported failure even when the model had answered.
