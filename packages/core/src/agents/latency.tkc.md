Latency-class definitions for agents. Defines three latency tiers (interactive 10s, considered 60s, background 3600s) and provides functions to assign agents to a class, look up the class for a given agent, check whether elapsed time is within tolerance, and format assignments as human-readable strings. Exports latencyinteractive, latencyconsidered, latencybackground, assign, classforagent, iswithintolerance, and formatassignment. Depends on shared.types, shared.log, and std.str.
