Pulls Ollama models with progress tracking, parsing stdout lines for download percentage, bytes transferred, and ETA. Also provides model availability checking via the Ollama API tags endpoint (`ismodelavailableat(baseurl;modelid)`, a GET through shared.reachability.localget whose body is read with the typed json accessors by `handlemodeltagsbody`; no answer is logged and reads as not available; VM1.6h) and listing of installed models. Depends on std.str, shared.log, std.process, std.json, shared.jsonobj and shared.reachability.
