The hold-until-approved gate for a `$requireapproval` policy decision (GA5.26). `create` records a pending approval for a request's binding and returns a 32-hex id; `approve`/`decline` decide a pending, unexpired approval once; `consume` spends an approved, unexpired approval for the same binding exactly once, in a single UPDATE; `refusal` and `decidefailure` explain a refusal after the fact. `binding` is a sha256 over the decision, the fallback selection and the UNSALTED anonymised text, so a re-submission (a new run with a new placeholder salt) binds the same. Rows in `approval_requests` (migration 36) hold no text; the client holds the text for re-submission. Declares no struct types, because `page.api.pipeline` is at toke's 64-struct limit (T-54). Depends on std.str, std.db, std.crypto.
