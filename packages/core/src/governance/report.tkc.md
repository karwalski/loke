Generates a periodic governance report — request counts, policy violations, quota breaches, top triggered rules — as markdown, and writes it to the filesystem. All four queries used to read `audit_events`, a table no migration creates; they read `audit_log` now with `ts` mapped to `created_at` (GA5.12). Two quantities have no source and say so rather than reporting zero as a finding: nothing writes `policy_deny`, `policy_require_approval` or `quota_exceeded` to the trail, so those counts mean "not recorded"; and `audit_log` has no rule identifier, so the top-triggered-rules section cannot be computed at all. `fromts`/`tots` are epoch milliseconds, matching `created_at`. Depends on std.db, std.str, std.fs, shared.log, std.time and core.storage.db.
