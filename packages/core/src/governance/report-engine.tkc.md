Generates the five governance report templates (compliance summary, PII detection log, routing decisions, policy changes, cost savings) from `audit_log`. Every template goes through one query builder and one window resolver, so the SELECT list, the date bounds and the ordering have a single spelling. The reporting window is resolved to epoch milliseconds by `core.storage.db.msrangeof` and bound as numbers against a CAST column (GA5.11) — comparing the ISO filter dates directly to `created_at` was a string comparison that matched nothing. Rows carry the row's `risk_tier` as severity and a per-template value, with cost formatted from exact integer hundredths (DA1.5). An unknown template and an unreadable window are each reported inside a real `$report` rather than as `$err`, because T-18 makes the error arm of a user-declared union dead; `knowntemplate()` is the plain-bool predicate a caller should use to reject a template up front. Depends on std.db, std.str, shared.log, shared.types, core.storage.audit and core.storage.db.
