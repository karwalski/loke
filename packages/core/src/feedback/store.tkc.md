Persists and retrieves feedback entries in SQLite, provides summary queries (thumbs-up rates over configurable day windows), manages submission state, and lists pending feedback for batch export. Also holds false-positive PII reports in pii_feedback, one row per report naming only the detection pattern, the verdict and the request id (T12.2). Depends on shared.types, core.feedback.types, core.storage.db, std.db, std.str, and shared.log.
