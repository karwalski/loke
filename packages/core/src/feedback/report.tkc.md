Issue reporting via GitHub. Creates structured issue reports (bug, feature, privacy concern, quality) and submits them as GitHub issues via the REST API, formatting the body with type, version, platform metadata, description, steps to reproduce, and expected behaviour. Exports typebug, typefeature, typeprivacy, typequality, newreport, formatgithubbody, and submittogithub. Depends on shared.types, std.http, std.json, shared.log, std.str and shared.utf8. `issuetitle` builds the issue title from the first 60 bytes of the description, cut at a UTF-8 character boundary (shared.utf8.prefix, F10.49).
