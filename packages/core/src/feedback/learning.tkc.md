Computes learning signals from feedback data (thumbs-up rates by feature area), derives routing adjustments based on those signals, and persists them to the settings store. Per-model adjustments, sensitivity review flags, and adaptations that can be listed and reverted (T12.2). A false-positive PII report, built from the flagged entity, is recorded against the core.privacy.regex pattern that produced it (never the value) and lowers that pattern's learned confidence, persisted as a revertable adaptation; detection does not consult the learned value. Depends on shared.types, shared.log, feedback.store, storage.db, std.db and core.privacy.regex.
