Priority-based job queue for local model inference requests. Manages job lifecycle (pending, running, completed, failed, cancelled) with user/agent/evaluation priority levels and provides formatted table output for queue inspection. Depends on shared.types, std.str, shared.log, shared.utf8, and core.models.queuetypes. `formatlist` cuts the model column (20 bytes, padded back) and the prompt preview (26 bytes) at a UTF-8 character boundary (shared.utf8.prefix, F10.49).
