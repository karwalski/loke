Ollama REST API client providing health checks, model listing, text generation, chat completion, model pulling, and model deletion. Wraps all Ollama endpoints with proper error handling and JSON parsing. Depends on std.http and std.json. LS1.1j added sendchatplain, which returns the completion text and "" for any failure. sendchat is kept and delegates. Two defects are fixed: callers could not discriminate sendchat's result (T-18), and the three inner matches used the match as an expression with an $err in the failure arm rather than returning early, so an HTTP failure went on to parse the error value as a response.
