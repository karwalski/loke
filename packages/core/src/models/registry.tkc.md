Model capability registry that catalogues available LLM models (cloud and local) with their quality scores, speed, context windows, and supported tasks. Provides lookup by task type with optional local-only and tier-speed filtering to find the best model for a given workload. Depends on shared.types, std.str, and std.json. LS1.1j added bestfortask and capabilitybyid, which return a plain $modelcapability, plus the nocapability sentinel (empty modelid) and the iscapability predicate. findbest and byid are kept and delegate. The plain forms exist because a caller of an X!$lokeerr result cannot discriminate the outcome under T-18. F5.3: excluding(registry;ids) returns the catalogue without the named models, which core.router.router.routechain uses to find the next fallback candidate.
