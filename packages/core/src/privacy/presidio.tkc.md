Client for the Microsoft Presidio PII detection sidecar. Sends text to the Presidio /analyze endpoint, parses entity results, maps entity types to sensitivity levels and confidence scores, and converts them to the internal PII entity format. Presidio's offsets count Unicode code points (Python str indices) and loke's strings are UTF-8 bytes, so `place` converts each span to byte offsets before taking its value (MK6.16); a span it cannot place exactly (outside the text, empty, blank, or in text that is not well-formed UTF-8) is counted unplaced, and the pipeline refuses a run with any. Detection only: it leaves .placeholder empty, because core.privacy.placeholder.assignplaceholders numbers the deduped list in one place. Depends on shared.types, std.http, std.json, and std.str.
