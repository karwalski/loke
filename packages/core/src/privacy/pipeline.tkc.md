Orchestrates the full privacy detection pipeline: regex scan, NER scan, Presidio scan, deduplication (of equal values the most sensitive is kept, RG1.7c), placeholder assignment (delegated to core.privacy.placeholder, salted with the request id), anonymisation, and guardian prompt injection. Produces a complete pipeline run result with per-stage metrics, sensitivity classification (never lower than the highest detection any masking layer accepted, before routing, consensus and dedup), and the final anonymised text. Depends on shared.types, std.str, shared.log, core.privacy.regex, core.privacy.presidio, core.privacy.ner, core.privacy.placeholder, core.privacy.guardian, and core.privacy.pipelinetypes.
