Persistent placeholder storage backed by SQLite. Stores placeholder-to-original mappings keyed by request id with a 24-hour expiry (`expires_at = datetime('now','+1 day')`, swept by `expireold`). Restoration is scoped to a single request: `restore` and `countforrequest` both query `WHERE request_id=?`, so a mapping is usable only by the request that created it — there is no restoration across sessions, and no cross-request or cross-prompt reuse of a mapping. Encryption at rest is not currently active (X8), so entries are plaintext on disk. Depends on core.storage.db and std.db.
