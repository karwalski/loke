Client of the privacy-filter sidecar (`packages/privacy-filter/server.py`, loopback port 11435). AD1.4: `new(baseurl;threshold)` / `fromconfig(cfg)` build a `$pfclient` carrying the operating point from `privacy.privacy_filter_threshold`, normalised by `normthreshold` to the text Python prints for the float (anything outside 0..1 is dropped). `detect` and `anonymise` post through `shared.reachability.localpost` (loopback only, text escaped), sending `threshold` only when one is configured so the sidecar's own default (`confidence_threshold` in `models.json`, or `LOKE_PF_THRESHOLD`) governs otherwise. Each answers a `$pfscan`: `ok` only when the sidecar answered with a scan, never an empty clean one on failure; `requested`, `applied` (the threshold the sidecar reports), `asrequested`, `suppressed`, `count` and the raw `body`. The threshold travels as JSON number text, never an f64 (T-20). `isavailable` is a real GET of `/health`; `listmodels` answers `/models` or "". No importer in loke yet (claims B9). Depends on std.json, std.str, shared.config, shared.jsonobj, shared.reachability.
