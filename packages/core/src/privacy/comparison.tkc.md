Privacy layer comparison for `loke privacy evaluate` (F3b.9). `compare` runs one text through every layer of a `$pipelineconfig`'s registry with the calls `core.privacy.pipeline.run` makes (`layerhealth.consult`, `layerconfig.accepted`/`masks`/`vetoes`, then `consensus.apply` under the configured strategy) but keeps each layer's own detections, state and reason. `reportlines`/`report` render it: per layer its detections as type, byte span and confidence (the value only when `showvalues` is true), an unavailable or failed layer as such and never as an empty result, and per consensus decision the reporting layer, the layers that found it, the voters that did not, and mask or pass. `labelledreport` scores a corpus-format JSONL file (tests/fixtures/pii-corpus) per layer and for the consensus outcome through `core.privacy.evaluation` (`corpuslabels`, `scoretext`, `scoreline`), printing recall, precision, F1 and tp/fp/fn and never a text or value; a layer is scored only on the texts it scanned. Depends on `std.str`, `std.json`, `shared.types`, `core.privacy.filterregistry`, `core.privacy.layerhealth`, `core.privacy.layerconfig`, `core.privacy.consensus`, `core.privacy.evaluation`, `core.privacy.pipeline`.
