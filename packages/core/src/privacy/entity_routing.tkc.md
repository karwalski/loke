Per-entity-type layer routing (F3b.5). Reads the `[[privacy.entity_routing]]` entries of a config.toml text line by line (std.toml has no array-of-tables accessor; the line reader's helpers are `core.privacy.layerconfig`'s): `entity_type` (a type some layer reports in `core.privacy.entityvocab`, matched without regard to case), `preferred_layers` (required, not empty) and `fallback_layers` (optional), each layer one the registry holds and one that reports the type. `resolve` returns the routes, or an error naming the line and no route, which `core.privacy.pipeline` turns into a refusal of every run (`refusal`). `apply` runs after the layers and before consensus: a routed type is accepted from its preferred layers that are available (completed, masking, not filtered out), else its available fallback layers, else from every layer that ran (noted, and logged by the pipeline). Unrouted types are untouched, and with no route the detections come back as given. The regex layer's detections are never dropped; a route for a type it reports that does not prefer it is warned about. Depends on `std.str`, `shared.types`, `core.privacy.filterregistry`, `core.privacy.entityvocab`, `core.privacy.layerconfig`.
