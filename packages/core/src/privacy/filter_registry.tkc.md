Privacy filter registry (F3b.1). The detection layers `core.privacy.pipeline.run` walks, in order: each `$privacyfilter` has an id, name, kind, declared entity types, nominal confidence, enabled state, URL and one client parameter, and since F3b.2 the settings `[[privacy.layers]]` gives it (`priority`, `mode`, `threshold`, `entityfilter`; defaults accept and mask everything). The default registry is regex, NER and Presidio enabled and the privacy-filter sidecar disabled, at priorities 1 to 4. Exports newregistry, register, replace, remove, get, has, list, listenabled, setenabled, seturl, setparam, setpolicy, sortbypriority (stable, lower first), the mode names and the layer ids, layers and defaultregistry. Depends on std.str and core.privacy.entityvocab.
