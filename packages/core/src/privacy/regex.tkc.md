Regex-based PII detection layer. Defines pattern definitions for ten entity types (email, AU/US phone, credit card, IPv4, AU TFN, AU ABN, US SSN, URL, API key) with associated sensitivity levels and confidence scores. Runs all patterns against input text, replaces matches with placeholders, tracks the highest sensitivity level found, and returns a full detection result. Exports getpatterns, detect, and detectwithpatterns. Depends on shared.types, core.privacy.patterns, core.privacy.placeholder, and std.str.
