Local NER (Named Entity Recognition) module that uses a small on-device model (qwen2.5:0.5b) to detect PII entities in text, falling back to Ollama if the model pool is unavailable. Also provides text embedding via the same local model. Detection only: it leaves .placeholder empty, because core.privacy.placeholder.assignplaceholders numbers the deduped list in one place. Depends on shared.types, core.models.infer, core.privacy.ner, shared.log, std.json, and std.str.
