Privacy filter evaluation and benchmarking. Computes precision, recall, and F1 scores for each detection layer by comparing detected entities against labelled ground truth, and formats results as summary strings. Exports computeprecision, computerecall, computef1, evaluatelayer, and formatresult, plus the basis-point forms (ratiobp, precisionbp, recallbp, f1bp, bplabel, evaluatelayerbp) that survive being returned to a test (T-20).

Since AD1.2 it also does the entity-level scoring every caller used to write for itself: corpuslabels reads a PII-corpus case into labelled spans (placelabel locates each value in the text as loke decoded it), entityspans and valuespans turn a layer's output into spans, scoretext scores one text into an $entityscore (recall over labelled entities overlapped by any detection, type-agnostic; false positives as merged regions overlapping no real PII), and entityrecallbp, directrecallbp, entityprecisionbp and scoreline report it, recall first. isdirectidentifier and directrecallfloorbp define the direct identifiers and the recall floor held on them (92.50%, reason in the source); meetsfloor fails on zero labelled. Used by tests/integration/test_detection_recall.tk (the floor) and tests/integration/test_layer_marginal.tk (AD1.3, per-layer marginal value). Depends on std.str, std.json and shared.types.
