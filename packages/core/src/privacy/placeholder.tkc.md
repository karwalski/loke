In-memory placeholder map that tracks original-to-placeholder mappings for PII entities. Owns the single placeholder format and the single placeholder generator: makesaltedplaceholder builds the token, saltforrequest derives the per-run salt from the request id, assignplaceholders numbers a whole deduped entity list from one per-type counter (PL1.1 — four detection layers previously numbered their own entities and collided), mapfromentities builds the restore table from that list, applytotext performs the substitution longest-value-first (substituting a name before its own prefix would forward the surname in the clear), and restore reverses it. Depends on shared.types and std.str.
