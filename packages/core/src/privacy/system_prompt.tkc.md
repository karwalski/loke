Runs a caller's system prompt through the privacy pipeline together with the text (F3.9b). The two are joined and scanned once by core.privacy.pipeline.run, so detection, consensus, dedup, placeholder numbering, sensitivity and the policy decision cover both; each part is then anonymised by value with the one entity list, so placeholders and restoration are shared. The run's result is the text alone and its finalsystemprompt is the guardian over the anonymised system prompt. A detection whose value is in neither part (one spanning the join) is counted as unplaced, so pipe.issafetoforward refuses the run. Exports run, runforward, anonymisedsystem and hascallersystem. Depends on core.privacy.pipeline, core.privacy.guardian, shared.log and std.str.
