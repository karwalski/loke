G2 reconciliation of the disclosure record against the audit trail (DA1.10, `docs/specifications/disclosure-accounting.md` §6.4). `reconcile` counts `disclosure_log` rows, `llm_dispatch` audit rows, disclosure rows with no audit row that records them (`llm_dispatch`, or `llm_request_refused` for a no-custody refusal), and `llm_dispatch` rows with no disclosure row, and lists the first 100 correlation ids each way. `$reconciliation.readable` is false when a query failed, and `reconciled` is then false too, so an unreadable store never reads as clean. `formatreconciliation` renders the report `loke audit verify` prints. A pair deleted together is not an orphan and is left to the hash chain (`core.storage.audit.verifychain`). Depends on std.db and core.storage.db. Tested by `tests/unit/audit/test_disclosure_chain.tk`.
