Per-layer privacy metrics as one JSON body (F3b.10), shared by `GET /api/layermetrics` (page.api.layermetrics) and the `layer_metrics` tool of loke's MCP server (mcptoke.tools). `metricsjsonfor(window)` builds the aggregates of core.audit.layermetrics over a window, `recorded:false` with no figure when no request recorded any; `bodyfor(window)` refuses an unknown window (400) or an unopenable store (503). Never a detected value.
