Audit metrics aggregation. Defines summary types for token savings, cost savings, cache hit rates, entities redacted, and per-provider breakdowns. Provides stub functions to query metric summaries, per-provider metrics, token savings time series, cache statistics, and data export for a given time period. Exports summary, emptysummary, byprovider, tokensavingsseries, cachestats, emptycachestats, and export. Depends on shared.types, std.db, and std.str.
