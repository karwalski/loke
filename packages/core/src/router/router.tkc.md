Main request router. Orchestrates intent classification, sensitivity scoring (from both PII results and content analysis), and model selection to produce a final routing decision. Maps model IDs to provider, context window, and cost metadata, estimates latency by tier, and logs each routing step. Exports newconfig, new, route, and helper functions tasktostr, providerfromstr, ctxfrommodel, costinfrommodel, costoutfrommodel. Depends on shared.types, core.router.intent, core.router.sensitivity, core.router.selector, core.models.registry, shared.log, and std.str. LS1.1j added routerequest, which returns a plain $routingdecision, plus the noroute sentinel (empty model id) and the isrouted predicate. route is kept and delegates. route previously bound selector.select's error value as a $selectionresult on every call and then read a field off it, so it segfaulted unconditionally. GA1.7/X8.6: $routerconfig carries a $routingstrategy, defaulting to local-first, which ranks an all-local candidate pool identically to the best-quality ranking the router already used, so the default changes nothing measurable. newconfigwith names a strategy and newconfigfull also reaches preferlocal and maxcostper1k, which were previously only settable by hand. iscloudprovider and isclouddecision are the route-level half of the safety property: routerequest refuses to return a decision naming a cloud provider for RESTRICTED data, independently of the selector's own refusal, because the route is the value a provider call is actually made from. tests/unit/router/test_route_safety.tk asserts it with a PUBLIC control that does reach a cloud provider, so the assertion cannot pass vacuously.
