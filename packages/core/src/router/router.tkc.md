Main request router. Orchestrates intent classification, sensitivity scoring (from both PII results and content analysis), and model selection to produce a final routing decision. Maps model IDs to provider, context window, and cost metadata, estimates latency by tier, and logs each routing step. Exports newconfig, new, routerequest, and helper functions tasktostr, providerfromstr, ctxfrommodel, costinfrommodel, costoutfrommodel. Depends on shared.types, core.router.intent, core.router.sensitivity, core.router.selector, core.models.registry, shared.log, and std.str. LS1.1j added routerequest, which returns a plain $routingdecision, plus the noroute sentinel (empty model id) and the isrouted predicate. route, the result-returning wrapper, was removed on 2026-09-27 once packages/cli ask moved to routerequest. It previously bound selector.select's error value as a $selectionresult on every call and then read a field off it, so it segfaulted unconditionally. GA1.7/X8.6: $routerconfig carries a $routingstrategy, defaulting to local-first, which ranks an all-local candidate pool identically to the best-quality ranking the router already used, so the default changes nothing measurable. newconfigwith names a strategy and newconfigfull also reaches preferlocal and maxcostper1k, which were previously only settable by hand. iscloudprovider and isclouddecision are the route-level half of the safety property: routerequest refuses to return a decision naming a cloud provider for RESTRICTED data, independently of the selector's own refusal, because the route is the value a provider call is actually made from. tests/unit/router/test_route_safety.tk asserts it with a PUBLIC control that does reach a cloud provider, so the assertion cannot pass vacuously. F5.3: $routerconfig carries fallbacktocloud. configfor builds a configuration from config.toml's [routing] table and configfromsettings from the settings key routing.strategy (strategy only, so the browser path cannot widen destinations), both through namedconfig, where an unknown strategy name means local-first. routedecided is the selection-plus-RESTRICTED-check half of routerequest. routechain returns a $fallbackchain (hops, the router's computed sensitivity, a note) built by re-asking the selector with the models already seen removed. hopallowed is the per-hop rule: local is always allowed, cloud never for RESTRICTED and never after a local first choice unless fallbacktocloud is on. Imports shared.config and core.storage.settings.
