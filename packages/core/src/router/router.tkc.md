Main request router. Orchestrates intent classification, sensitivity scoring (from both PII results and content analysis), and model selection to produce a final routing decision. Maps model IDs to provider, context window, and cost metadata, estimates latency by tier, and logs each routing step. Exports newconfig, new, route, and helper functions tasktostr, providerfromstr, ctxfrommodel, costinfrommodel, costoutfrommodel. Depends on shared.types, core.router.intent, core.router.sensitivity, core.router.selector, core.models.registry, shared.log, and std.str.
