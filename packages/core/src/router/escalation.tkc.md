Model escalation logic that determines when a response is inadequate (empty, too short, or contains uncertainty phrases) and selects a stronger model to retry. Maintains a ladder from small Ollama models up to Claude Sonnet. F5.8: `shouldescalate(response;policy;attempts)` honours the policy's retry budget; `escalationtarget(model;policy;level)` returns "" (do not escalate) for an unrecognised or empty model id and at the top rung, and refuses a cloud rung unless the policy allows cloud escalation AND `core.router.sensitivity.canusecloud(level)`. `minconfidence` was removed because nothing could honour it. Not imported by any request path yet. Depends on shared.types, shared.log, core.providers.types and core.router.sensitivity.
