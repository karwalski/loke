Routing example store backed by vector search. Stores confirmed prompt-to-model routing decisions as vector embeddings in a vector store collection, enabling similarity search to find past routing examples that match a new prompt. Supports adding examples, querying for similar examples by embedding, and formatting results. Exports open, collection, addexample, findsimilar, and formatexamples. Depends on std.vecstore, shared.log, std.json, std.str, and std.time.
