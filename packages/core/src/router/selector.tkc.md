Model selector that chooses the best model for a request based on task type, sensitivity level, latency tolerance, and cost constraints. Enforces local-only routing for RESTRICTED data and falls back to cloud models when no local option is available. Depends on shared.types, core.models.registry, std.str, and shared.log. LS1.1j added selectmodel, which returns a plain $selectionresult, plus the noselection sentinel (empty modelid, reason carrying the message) and the isselected predicate. select is kept and delegates. This matters most for the RESTRICTED path: select returns $selectionresult!$lokeerr and under T-18 a caller could not tell a refusal from a selection, which is what kept GA1.7 unwired. select also had a second defect — its internal match on reg.findbest put the $lokeerr arm first, so it returned $err for every input. estimatecost was returning 0.0 unconditionally for the same reason and is fixed; estimatecosthundredths is the form to cross a module boundary with (T-20).
