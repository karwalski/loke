RouteLLM integration client that queries the local RouteLLM service to get a weak/strong routing signal and confidence score for a given prompt. Falls back gracefully when the service is unavailable. Depends on shared.types, std.http, std.json, std.str, and shared.log. F3b.14: the default address is defaulturl(), http://127.0.0.1:11461 (it was localhost:11431, the CLI proxy's port), and isavailableat(url) joins queryat(url;...) for a non-default sidecar.
