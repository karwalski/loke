Fact extraction module that mines text from various sources (clipboard, files, raw text) into memory palace drawers. Splits text into sentences, filters by length, encodes via AAAK, and stores results. Provides formatted result tables for reporting. Depends on shared.types, shared.log, core.memory.storage, core.memory.aaak, core.memory.palace, std.str, std.file, std.clipboard, and core.memory.types.
