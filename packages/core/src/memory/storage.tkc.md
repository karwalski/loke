Storage layer for memory palace drawers and closets, handling CRUD operations against the SQLite database. Includes content-based location classification that routes memories to appropriate wings/halls based on keywords. Depends on std.db and core.memory.types. storedrawer writes the drawer and its memory_scores row in one BEGIN/COMMIT transaction (M1.7a), flagging CONFIDENTIAL and RESTRICTED drawers as PII at creation and stamping the score's created_at in epoch seconds.
