MCP tool server for memory palace operations, exposing search, store, context loading, status, facts lookup, and agent diary writing as MCP-compatible tools. Routes incoming tool calls to the appropriate memory subsystem handler. Free text in every answer is quoted with `jx.escape` and string arguments are read with `jx.strvalue` (MK6.11: `json.enc` leaves a newline raw, `json.str` turns one into the letter n). Depends on core.mcp.protocol, core.memory.palace, core.memory.storage, and core.memory.search.
