MCP tool server for memory palace operations, exposing search, store, context loading, status, facts lookup, and agent diary writing as MCP-compatible tools. Routes incoming tool calls to the appropriate memory subsystem handler. Free text in every answer is quoted with `jx.escape` and string arguments are read with `jx.strvalue` (MK6.11: `json.enc` leaves a newline raw, `json.str` turns one into the letter n). memory.store classifies each note locally with the privacy pipeline's regex layer (`core.privacy.regex.detect`) and stores the drawer at the level found, so a note holding an email address or a card number is CONFIDENTIAL or RESTRICTED and `pii_flagged` (MK6.19); it used to store everything PUBLIC. Depends on core.mcp.protocol, core.memory.palace, core.memory.storage, core.memory.search, and core.privacy.regex.
