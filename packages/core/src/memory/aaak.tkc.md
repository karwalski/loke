Implements AAAK (Abbreviated Associative Archival Knowledge) compression for memory palace content. Encodes facts using pattern-matched shorthand (decisions, team structures, copula statements) at configurable compression levels (light/medium/aggressive). Provides encode, decode, and compression ratio measurement. Depends on std.str, shared.utf8 and core.memory.types. A long word's 4-byte abbreviation is cut at a UTF-8 character boundary (shared.utf8.prefix, F10.49).
