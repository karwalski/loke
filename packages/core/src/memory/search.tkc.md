Keyword-based search engine for the memory palace. Extracts keywords from queries, scores drawers by summing index weights, and returns ranked results with content excerpts. Supports wing-scoped searching and provides keyword indexing for new drawers. Depends on shared.types, core.memory.types, std.db, std.str, shared.log, shared.utf8, and std.json. The excerpt is at most 200 bytes, cut at a UTF-8 character boundary (shared.utf8.prefix, F10.49).
