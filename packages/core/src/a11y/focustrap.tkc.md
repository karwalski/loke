JavaScript for a modal focus trap with initial-focus choice, Escape to deactivate, inert and aria-hidden siblings, and focus restoration, built around focusableselector. Ported from src/platform/a11y/focus-trap.tk (F10.12-T2), with the emitted JavaScript repaired (it did not parse, and its = comparisons made every key deactivate the trap). Exports focusableselector and focustrapjs. Depends on std.str.
