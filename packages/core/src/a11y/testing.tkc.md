Static accessibility check of an HTML string for images without alt, unlabelled inputs (aria-label, aria-labelledby, label for, or an enclosing label) and empty role attributes, examining every tag; result and violation JSON with escaped strings. Ported from src/platform/a11y/testing.tk (F10.12-T2), whose checker examined only the first tag of each kind and discarded every violation it found. Exports checkhtml, violationtojson, resulttojson and assertnoviolations. Depends on std.str, std.time and shared.jsonobj.
