Stateless key lookup and value formatting for user-facing strings, ported from src/platform/i18n/translator.tk (F10.12-T1). Resolves a key against a locale table from core.i18n.locales and returns the key itself when there is no entry; exports defaultlocale, getlocale, haslocale, localefor, lookup, tfor, t, tn, tparams, setlocale, formatnumber, formatdate, and formatrelative. There is no mutable module state, so setlocale records the request and reports whether the code is one this build ships rather than changing the active locale. Depends on core.i18n.locales, std.str, shared.log, and shared.types.
