File-based policy watcher that monitors enterprise, team, and user policy files for changes using a hash-based approach. On change detection it reloads, merges, and validates the policy tiers. Depends on core.policy.schema, core.policy.loader, core.policy.merge, core.policy.validate, std.file, std.str, std.crypto, and shared.log. The change key `hashfile` is a SHA-256 of the whole file (F10.49); it was the length and the first 64 bytes, which could hold a split UTF-8 character and missed a same-length edit after byte 64.
