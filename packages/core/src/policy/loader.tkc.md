Policy set loader. Loads policy sets from local JSON files in a configurable directory and optionally from an enterprise URL, parses regulation rules, evaluates loaded policies against request context and sensitivity to produce policy violations, supports hot-reload detection, and formats violation reports. Exports defaultconfig, loadfile, loadurl, loadall, checkreloadneeded, evaluate, and formatviolations. Depends on core.policy.types, std.file, std.http, std.json, shared.log, std.str, and std.time.
