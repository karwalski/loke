Policy set loader. Loads policy sets from local JSON files in a configurable directory and optionally from an enterprise URL, parses regulation rules, evaluates loaded policies against request context and sensitivity to produce policy violations, supports hot-reload detection, and formats violation reports. Also loads the built-in presets by name: `presetnames`, `presetknown`, `loadpreset`, `loadpresets`, `builtinset` and `evaluatepreset` project a preset from `core.policy.presets.registry` into the `$policyset` shape `evaluate` already consumes, so a shipped preset is enforceable rather than being a document nothing can reach. An unrecognised name yields a set whose single regulation has an empty rule list; `presetknown` is what tells that apart from a preset that genuinely constrains nothing, because T-18 makes the `$err` arm of a user-declared error side dead code. Exports defaultconfig, loadfile, loadurl, loadall, checkreloadneeded, evaluate, formatviolations and the six preset functions. Depends on core.policy.types, core.policy.presets.registry, std.file, std.http, std.json, shared.log, std.str, and std.time.
