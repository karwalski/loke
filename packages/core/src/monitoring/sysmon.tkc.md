System monitoring module that collects CPU, RAM and process statistics on macOS from sysctl, vm_stat, top and ps, and serialises a snapshot to JSON. The parsers are separate functions so they can be tested on canned output: vmstatusedmb (active, wired and compressed pages at the page size vm_stat states), vmstatpagesize, and topbusypercent (100 minus top's idle figure). getprocessstats finds a process by name; getprocessstatsbypid reads one pid. snapshot() reports the calling process as loke (os.getpid); snapshotof(0) leaves the loke entry unmeasured, and tojson writes any process not found as null. Depends on std.os, std.process and std.str.
