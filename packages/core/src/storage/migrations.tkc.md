Schema migration definitions. Returns the ordered list of SQL migrations: `schema_migrations`, `settings`, `audit_log`, `placeholder_maps` and `sessions`, then the two append-only triggers on `audit_log` that reject `UPDATE` and `DELETE` (GA5.9). One migration is one SQL statement, because the runner applies each with `std.db.exec`, which compiles only the first statement in the string and discards the rest silently — which is why the two triggers are two migrations. No imports.
