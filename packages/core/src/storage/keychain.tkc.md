OS keychain integration module. Stores and retrieves API keys, the database encryption key, and other secrets via the platform keychain (macOS Keychain). Depends on std.keychain, shared.log, and std.str. `lastkind()` reports why the most recent call failed (`notfound` is the only kind meaning absent; X8.3). The module holds no keychain handle: tests redirect it to a throwaway keychain file with `std.keychain.use` (X8.7).
