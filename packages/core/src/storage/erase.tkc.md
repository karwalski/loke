Delete everything, verifiably (X8.4). eraseeverything drops every table in loke.db (enumerated from sqlite_master, audit_log included), empties the sqlite_ bookkeeping tables, rebuilds the schema through the migrations and VACUUMs with secure_delete on, then unlinks every other regular file under the data directory except config.toml and bin/. Returns a plain $eraseresult; refuses a data directory that is not absolute or holds no loke.db. Proven by tests/unit/storage/test_erase_everything.tk, which reads every byte of every file for each fixture in plain, hex and double-hex form. Depends on std.db, std.file, std.str, shared.log, core.storage.db and core.storage.migrations.
