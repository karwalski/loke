Semantic prompt cache backed by a vector store. Embeds prompts and performs similarity search to find cached responses above a configurable threshold, with TTL-based expiry. Depends on std.vecstore, models.infer, std.json, std.str, std.time, and shared.log. GA1.6: lookup answers with $cachehit{response;score;ageseconds} instead of $cacheresult, whose $some carried an i64 and was always constructed as $some:0 — so a hit returned the literal zero and the type could not hold a response at all. nohit() is the sentinel (empty response) and ishit() the predicate; lookupresult is kept for any caller still matching the old result. score is an f64 field of a returned struct, which crosses a module boundary intact (T-20). open and collection were returning std.vecstore's RESULT wrappers as bare i64 handles, so a caller held a pointer to a result rather than to a store; they match the result now and answer 0 for failure. Embeddings are converted element by element from @f32 to @(f64): inf.embed answers @f32 and vecstore's upsert and search take @(f64), and handing one to the other was reading 4-byte floats as 8-byte ones. The payload is read through the typed json.dec/json.str/json.i64 with $ok written FIRST, because a stdlib result's match arms bind by position, not by label. formatstats had no `<` at all and returned garbage. The `collection` parameter is named vstore because a parameter sharing a name with a function in the module resolves to the function.
