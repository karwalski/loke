Budget enforcement and tracking. Creates budget managers with configurable daily/monthly token and cost limits, checks whether a request fits within all active budget periods (warning when thresholds are approached), records actual token and cost usage after requests, resets usage for a given period, and formats current usage as a human-readable summary. Exports new, defaultlimits, periodlabel, check, record, resetperiod, and formatusage. Depends on shared.types, std.str, shared.log, and core.optimiser.budgettypes.
