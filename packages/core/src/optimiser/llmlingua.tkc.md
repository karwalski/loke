Client for the LLMLingua prompt compression sidecar. Ratio-based (`compress`) and token-target (`compressauto`) compression, posted through shared.reachability.localpost to a loopback sidecar only; both answer a plain `$compressresult`, read with `iscompressed` (an empty `compressed` with a `failure` reason is the failure sentinel; use the original prompt then) and `compressfailure` (LS1.1x). Also `isavailable` and `shouldcompress`. Depends on std.json, std.str, shared.log, shared.reachability and shared.jsonobj.
