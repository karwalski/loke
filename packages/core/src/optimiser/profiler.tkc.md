Dataset profiler that analyses JSON arrays to produce column-level statistics including type inference, null counts, uniqueness, min/max, PII candidate detection, and TOON schema output. `profilejson` answers a plain `$profiled` (read with `isprofiled`; its `failure` names why: not JSON, not a JSON array, rows that are not objects) for callers in other modules, which cannot match `profilejsonarray`'s `$datasetprofile!$lokeerr` (T-18; MK6.10). Depends on shared.types, core.optimiser.toon, std.str, and std.json.
