TOON (toon-format/toon) for mcp-toke's compress and decompress, plus the older type-tag classifier. `jsontotoon` and `toontojson` (MK6.7) are a codec that reads the JSON or TOON text itself and carries every value: a single value, an object of single values and arrays, an array of single values, an array of objects sharing one key order (TOON's tabular form), and an empty array. Anything else (a nested object, an array of arrays, mixed arrays, rows whose keys differ, an empty object, an exponent, a \u, \/, \b or \f escape) is refused with a reason from `encodejson`/`decodetoon` (`$jpart`, read with `isencoded`); the string forms answer "" on failure, read with `isconverted`. Numbers and string escapes are carried as written, so decoding what was encoded gives the input minus insignificant whitespace (`jsonminified`). `encode`, `decode`, `fromjsonstr` and `$toonvalue` are still the classifier that records only the KIND of a value (see the GA1.5 note in the source). Also a character-ratio savings measure in basis points. Depends on std.str, std.json, core.optimiser.toontypes, shared.jsonobj and shared.utf8. `truncate` cuts in bytes at a UTF-8 character boundary (shared.utf8.prefix, F10.49).
