TOON (Token-Optimised Object Notation) type-tag classifier between JSON and a compact pipe-delimited representation; it records the KIND of each value, not the value, so it is not yet a codec (see the GA1.5 note in the source). Entry points answer plain values (LS1.1x): `fromjsonstr` and `decode` return `$toonparsed`, read with `isparsed`; `jsontotoon` and `toontojson` return a string that is "" on failure, read with `isconverted`. Also table encoding and a character-ratio savings measure. Depends on std.str, std.json and core.optimiser.toontypes.
