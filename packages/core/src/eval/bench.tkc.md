Runs benchmark suites against LLM models, scoring responses by keyword matching, tracking latency and cost per case, and formatting results as tabular reports. Depends on shared.types, shared.log, providers.types, providers.dispatcher, and std.json. LS1.1j migrated runcase from disp.dispatch onto disp.trydispatch and disp.isdispatched. The match it replaces took its $ok arm on failure too and read response.content off a $lokeerr value, so the benchmark segfaulted on the first provider error.

VM1.6 gave it an entry point and persistence. `loke benchmark <model> [--out <path>]` (packages/cli) runs `defaultcases()` against a local Ollama model only: `iscloudmodel` refuses claude* and gpt* before anything is dispatched, and the CLI builds its dispatcher with empty API keys. `modelversion` looks up the installed model's Ollama digest, which is recorded as the pinned model version; with no digest nothing is recorded, though the table is still printed. `record` writes two VM1.1 measurements through `core.eval.resultsink`, `keyword_score` (ratio) and `latency_mean` (ms), over workload `defaultworkload()`, with the numbers formatted to str in this module (T-20). A run in which any case failed to dispatch is not recorded, because `casefailed` scores a failure as 0.0. The seed is recorded null, with a caveat, because `core.models.ollama.sendchatplain` does not forward the request's temperature. `defaultresultspath` is `~/.loke/benchmarks/<date>.jsonl`. Exercised end to end by `scripts/smoke_benchmark.sh`.
