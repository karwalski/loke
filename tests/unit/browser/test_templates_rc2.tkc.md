Renders every page template of loke (`packages/browser/templates`) and moke (`packages/moke/templates`) through the pinned ooke template engine, `ooke.template.tplrenderfile` (3.0.0-rc.2), from the repository root. Each page must fill the base layout's title and add more than 200 bytes of content to it; a page whose blocks never closed renders the base layout alone. Pins the F10.8 fixes: `/tabs` and `/privacy` closed their blocks with directives rc.2 does not know (`endblock`, `/block`) and rendered empty, and `/installer`'s `raw` directive rendered nothing, so the hardware JSON now arrives escaped in data attributes. Depends on `std.test`, `std.str` and `ooke.template`.
