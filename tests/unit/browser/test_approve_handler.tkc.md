Unit tests for the browser approve API handler (`page.api.approve`). The endpoint was a stub returning a constant `{"ok":true,"action":"approved"}`; since GA5.26 it decides a pending approval in `core.governance.approvalgate`. Covers the success and failure response bodies and the decision vocabulary (`approve`, `decline`, absent, anything else). The gate's behaviour is tested against a real store in `tests/unit/governance/test_approval_gate.tk` and over HTTP in `scripts/smoke_e2e.sh`.
