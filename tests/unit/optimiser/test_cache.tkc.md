Tests `core.optimiser.cache` by importing it (X7.2). The file it replaces declared six stand-ins including `f=defaultthreshold():i64{ <92 }` — the module's threshold is an `f64` of `0.92` on a `$cacheconfig` and it has no `defaultthreshold` at all — and its own `lookup(score;age;ttl;threshold):i64` over four integers, where the real `lookup` takes a collection handle, a prompt, an inference pool and a config. So it could catch neither of the module's two real defects: `formatstats`'s body was a bare expression with no `<`, returning garbage (T-19), and GA1.6, where `lookup` returned `$some:0` on every hit so the response could never be handed over. Covers: `embedmodel`, `defaultconfig` by value; the `$cachehit` sentinel and `ishit`, including that an empty response collapses to the sentinel even at a perfect score so it cannot collide with real data; `hitfrom` carrying the response (the GA1.6 regression); `cacheparsewarn`; a real `std.vecstore` open and `prompt_cache` collection, plus the `collection(0)` guard that could not be written until the parameter was renamed off the `store` function; **the fail-safe — an empty inference pool means a lookup MISS and a declined store, never a match on a zero vector**, which is the property that matters in a privacy product where the failure mode is serving one viewer's cached answer to another; `lookupresult`'s `$none` (a plain user sum, so `mt` discriminates); `evictexpired`; and `formatstats` by content. **Carries a documented finding**: reading an element out of an `@f32` is broken in this toolchain — `@(1.5 as f32).get(0) as f64` yields `4.60943e+18`, the IEEE-754 bit pattern of 1.5 read as a number, while a scalar `f32` and an `@f64` array are both fine — so `tof64`'s element VALUES cannot be asserted from toke and only its length is. `tof64`'s body uses that same accessor, so whether the conversion added to fix the f32/f64 width mismatch is itself converting garbage cannot be settled without a loaded `nomic-embed-text`. Depends on `std.test`, `std.str`, `std.file`, `std`, `core.models.infer`, `core.optimiser.cache`.
