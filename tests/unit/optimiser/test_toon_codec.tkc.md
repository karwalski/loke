MK6.7 — `core.optimiser.toon`'s codec, which mcp-toke's compress and decompress call. Nine round trips, each asserting the exact TOON written and that decoding it gives back the input without its insignificant whitespace: the two-row array that used to encode to `~` (`[2]{a}:` and two indented rows), a flat object, an object holding a table, a list and an empty list written with whitespace, strings TOON must quote (empty, padded, `true`, number-like, `-x`, a colon, an escaped quote, an escaped newline) beside one it need not, numbers as written with the literals, keys quoted only when they are not identifiers, a single string, a single number and an empty array. Twelve refusals, each with its reason and the not-converted sentinel: nested object, array of arrays, rows with different keys or key order, mixed array, empty object, exponent, `\u` escape, non-JSON, truncated JSON, trailing text, empty input. Eight malformed TOON documents that must not decode: counts that disagree with values or rows, a short row, an over-indented row, a nested object, the classifier's old `HDR[` header, stray text, a bare value TOON would have quoted. Mutants, each restored and checked with `cmp`: jsontotoon put back on the classifier, nothing quoted, the list count check removed. Depends on `std.test`, `std.str`, `core.optimiser.toon`.
