MK6.7 — mcp-toke's compress and decompress tools through `handletool`, as the server calls them for tools/call. compress of `[{"a":1},{"a":2}]` (which answered `{"toon":"~","savings_pct":94}`) must answer the TOON table and the measured lengths: 17 JSON characters, 17 minified, 15 TOON, an 11% saving on both. A padded input is measured as sent (22 characters, 31%) and as minified (11%). A TOON longer than its JSON is a negative saving (-42%). A nested object is refused, named, with no saving. decompress gives back the original JSON, and refuses TOON whose count disagrees with its values. Assertions match fragments of the MCP envelope, whose inner JSON is escaped once. Mutant, restored and checked with `cmp`: compress reporting an invented saving. Depends on `std.test`, `std.str`, `core.mcp.protocol`, `mcptoke.tools`.
