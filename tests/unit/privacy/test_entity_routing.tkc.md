Tests `core.privacy.entityrouting` (F3b.5) on its own. Reading: no routing in an empty text or one with only settings and `[[privacy.layers]]`; a route's type and layer lists; optional fallback, single quotes, trailing comma and comment. The regex guard at config time: a route for CREDIT_CARD or au_tfn that does not prefer the regex layer warns; one that prefers it does not. Twenty-one malformed inputs, each refused with no route applied and an error naming a config.toml line (table form, inline forms, unknown or repeated key, no value, not key = value, missing or unquoted type, a type no layer reports, missing, empty or non-array layer lists, unquoted or unknown layer, a layer that does not report the type, a layer named twice, a duplicate route in another case, and one good route beside a bad one). At run time, on a fixed detection list: no route keeps everything in order; preferred layers win; case-insensitive match; a preferred layer that did not run, failed, or filters the type out gives way to the fallback (noted); neither available accepts every layer (noted); the regex layer's credit_card survives a CREDIT_CARD route to Presidio. Replaces the X7.2 test of the old, unimported route table. Depends on `std.test`, `std.str`, `core.privacy.filterregistry`, `core.privacy.entityrouting`.
