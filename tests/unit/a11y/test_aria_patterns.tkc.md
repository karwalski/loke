Unit tests for semantic HTML helpers and ARIA pattern attribute generators. Covers semantic elements (header, footer, aside, fieldset, section, nav, main, button) and ARIA widget attributes (dialog, alertdialog, tab/tablist/tabpanel, menu/menuitem, toolbar, switch, tooltip, status, progressbar, combobox). Depends on loke.platform.a11y.semantic, loke.platform.a11y.ariapatterns, std.str, shared.log.
