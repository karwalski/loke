MK6.19 — memory.store classifies what it stores, through `core.memory.mcpserver.handlememorytool`. Three notes are stored and each drawer is read back from the palace by the id memory.store reported: a note holding an email address must be CONFIDENTIAL and `pii_flagged`, a note holding a card number RESTRICTED and flagged, a plain note PUBLIC and unflagged. `core.memory.privacy.forgetpii` ("forget my personal data") must then remove exactly the two flagged notes and keep the plain one, and neither stored value may appear in the log. Before MK6.19 memory.store wrote every drawer PUBLIC, so the first five classification assertions and the forgetpii ones failed. Depends on `std.test`, `std.str`, `std.file`, `std`, `std.json`, `std.db`, `core.mcp.protocol`, `core.storage.db`, `core.memory.mcpserver`, `core.memory.privacy`, `shared.log`.
