Tests the wing model of `core.memory.palace` against a real migrated store (T6.1). A wing is the `wing` column of stored drawers, so the row's add/get/list clauses are asserted as: zero stored wings and four defaults on a new palace, one new wing per new wing name written through `core.memory.storage.storedrawer`, halls and rooms retrieved per wing, nothing for an unknown wing, the `$wing` type's fields, and `walk` rendering every wing with drawer counts. Depends on `std.test`, `std.str`, `std.file`, `std`, `core.storage.db`, `core.memory.palace`, `core.memory.storage`, `core.memory.types`, `shared.types`.
