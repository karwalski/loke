Tests `shared.origin`, the cross-origin refusal every state-changing loke endpoint applies first (GA2.6). Covers the allowed cases (no Origin header, loke and moke on loopback, IPv6 loopback, no port) and the refused ones: a foreign origin, `null`, and three prefix tricks that begin with an allowed string. The header value is tested directly because a test cannot build an http request (T-16). `scripts/smoke_serve.sh` checks the same rule through the running server. Depends on `std.test` and `shared.origin`.
