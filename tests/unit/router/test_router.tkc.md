Tests `core.router.router` by importing it (X7.2). The file it replaces declared a routing table for a model set the product has never had — `llama3`, `mistral-7b`, `claude-sonnet` — in a `routerequest(task:str;sensitivity:i64;preferlocal:i64):str` whose real counterpart takes six parameters of which none is a string task name or an i64 sensitivity. Fifteen assertions, all green, throughout a period in which the real `route` **segfaulted unconditionally on every call**: its internal match was written with the `$lokeerr` arm first, so `result` was bound to the error value on every success and `specfromresult` dereferenced a `$lokeerr` sum as a struct (LS1.1j). Covers: `tasktostr` for all eight tasks, which must round-trip against `intent.taskfromstr`; `providerfromstr` for all seven names plus the selector→router round trip, and the fail-safe-but-silent fallback of an unrecognised name to `$local` (safe for the gate, and it also means a misspelt provider is not diagnosed); **`iscloudprovider` for all seven tags with a discrimination assertion**, since this predicate is the one place in the routing path where the privacy invariant is enforced by the machine rather than by review; `ctxfrommodel` including that `qwen2.5:7b` and `qwen2.5:72b` are not confused by a prefix match and that an unknown model gets a conservative 32k rather than the largest window; `specfromresult` and `estimatelatency` read through the returned struct's FIELDS, because `costinfrommodel`/`costoutfrommodel` return bare `f64`s that T-20 corrupts across a boundary; `isclouddecision`, including that `noroute` names `$local` so a refusal cannot be dispatched to a cloud endpoint; and **the route-level safety property end to end through `routerequest` under a hostile configuration** (`preferlocal:false`, best-quality strategy — the setting that would otherwise prefer claude-3-5-sonnet at qualityscore 0.95) for three paths: an explicitly RESTRICTED request, a request made RESTRICTED by its text alone with zero PII entities, and a request escalated to RESTRICTED by four CONFIDENTIAL entities. A PUBLIC contrast is asserted to be cloud-routed so none of those passes on a router that refuses everything, and the default `newconfig` is asserted to route locally, which is what the README claims loke is. `route` is not asserted: its `$err` arm is unreachable under T-18. `intent.classify` is pointed at a closed local port so no network is required. Depends on `std.test`, `std.str`, `shared.types`, `core.router.strategy`, `core.router.selector`, `core.router.router`.
