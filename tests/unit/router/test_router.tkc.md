Tests the LLM router that selects the optimal model for each request. Verifies that critical sensitivity always routes to local models, user local-preference is respected, task-based routing selects appropriate cloud models (gpt-4o for code, claude-sonnet for chat), and fallback to llama3 for unrecognised tasks. Uses stubs mirroring `core.router.selector`. Depends on `std.test` and `std.str`.
