LS1.1j — the assertion T-18 made impossible: that a failure is distinguishable from a success. Drives the real modules rather than stubs, across all five layers of the request path that LS1.1j converted: core.models.registry (bestfortask / iscapability / capabilitybyid), core.router.selector (selectmodel / isselected / noselection), core.router.router (routerequest / isrouted / noroute), core.providers.types (nocompletion / iscompletion / completionerror) and core.providers.dispatcher (trydispatch / isdispatched / dispatcherror, plus guardedrequest). The safety-critical case is a RESTRICTED request no local model can serve: it must be refused, must name no model and no provider, and must be seen to be refused, because a caller that read it as a success would forward restricted data to whatever provider string it took out of the error payload — the failure GA1.7 was left unwired to avoid. One assertion is a deliberate T-18 witness: select's result still reports $ok for that refusal, and if that assertion ever fails, T-18 has been fixed upstream and the delegating result-returning wrappers can be retired. No network: every path is pure or aimed at a closed local port. Depends on std.test, std.str, shared.types, core.models.registry, core.router.selector, core.router.router, core.providers.types, and core.providers.dispatcher.
