Tests `core.providers.dispatcher` by importing it (X7.2), with `shared.types` for the `$provider` sum and `core.providers.types` for `$completionrequest`/`$apikeys`. The file it replaces declared its own provider-selection function, so it could see neither of the module's recorded defects: every `dispatch*` returns a result whose error arm T-18 makes dead (and reading a field off the mis-bound value **segfaults**, so `mt disp.dispatch(…){ $ok:r r.content; $err:e "" }` — which `packages/cli/src/{ask,proxy}.tk` still write — crashes the process the moment a provider call fails); and `trydispatch`'s arm list was `$anthropic, $openai, $ollama, $local, $ok`, so `$google`, `$mistral` and `$openrouter` had **no arm at all** while `$ok` is not a variant of `$provider`, and toke accepted the bogus name silently. The four network-reaching `trydispatch*` functions are not called. Covers the dispatcher's configuration (with `d.keys` bound to an annotated local, because `anthropic`/`openai` are field names on more than one struct at different offsets and an unannotated read raises E4034); the `isdispatched`/`dispatcherror` sentinel in both directions; and **provider selection across the three variants that used to fall through**, each required to name itself and to report a reason distinct from the others, so a match that collapsed them would fail. The largest part is the **guardian system prompt**, which is a privacy control: the version marker, and each of the five rules by name — personal information, placeholder tokens (including the exact instruction never to "guess, reconstruct, infer, or reveal the original value", which is what stops a model attacking the anonymisation), prompt injection, and audit. Also asserts that the request survives reconstruction with its model, messages and `maxtokens` intact (T-26 means there is no field assignment in toke, so the request is rebuilt rather than patched, and a rebuild that dropped the messages would send the guardian prompt and no conversation); that a caller's own system prompt is kept rather than replaced; and that guarding an already-guarded request is idempotent, which is what the `LOKE_GUARDIAN_v` marker is for. Depends on `std.test`, `std.str`, `shared.types`, `core.providers.types`, `core.providers.dispatcher`.
