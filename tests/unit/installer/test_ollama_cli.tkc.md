Tests the installer's `ollama list`, `ollama rm`, `ollama pull` and `test -x` (F10.40): `core.installer.ollamacli.run` and the production callers `pull.listinstalledmodels`, `uninstall.listremovableat`/`uninstallmodelat`, `updater.getinstalleddigest`/`updatemodel` and `autostart.isconfigured`. The work runs in a child (this binary again, through env(1)) whose PATH holds only `tests/fixtures/fake-ollama/ollama`, /usr/bin and /bin, so the real ollama is never run; the stand-in records each argv. Checks exact argv, that an argument holding spaces, `;` and `$` reaches the program as one unexpanded element, that a non-zero exit is a failure, and that `rm`/`pull` refuse an id that is an option. Depends on `std.test`, `std.io`, `std.str`, `std.file`, `std.args`, `std.process` and the `core.installer` modules above.
