Tests `core.governance.approvalgate` (GA5.26) against the production module and a real, migrated store. `consume` must answer true exactly once, for an approval that exists, was approved, has not expired and was issued for this request's binding. Asserts each refusal: before approval (`not_approved`), for another request (`mismatch`, and the attempt does not spend it), a second use (`already_used`), after expiry with the clock as a parameter (`expired`), after a decline (`declined`), and an id nobody issued (`unknown`). Also asserts that the binding is a deterministic sha256 that changes with the text, decision and selector, and that the stored row holds no text, placeholder or value. Depends on `std.test`, `std.str`, `std.file`, `std`, `std.db`, `core.storage.db`, `core.governance.approvalgate`.
