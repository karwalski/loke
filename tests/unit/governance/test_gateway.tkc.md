Tests the governance gateway policy enforcement. Verifies that admin role bypasses all restrictions, dangerous actions (delete_all, export_raw, disable_privacy) are denied for non-admins, standard actions (query, submit) are allowed, and unknown actions default to deny. Covers the policy evaluation wired into the request path by GA1.8. Uses stubs mirroring `core.governance.gateway`. Depends on `std.test` and `std.str`.
