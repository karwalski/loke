Tests the governance alert system. Verifies alert creation with kind and severity encoding, default configuration values (20% threshold, log-only mode), JSON serialisation of alerts, quota alert triggering logic (remaining percentage vs threshold, exceeded flag override), and severity classification for both quota alerts (warn vs critical on exceeded) and policy alerts (critical on DENY). Uses stubs mirroring `core.governance.alert`. Depends on `std.test` and `std.str`.
