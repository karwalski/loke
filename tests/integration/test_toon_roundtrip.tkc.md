End-to-end integration tests for the TOON (Token-Optimised Object Notation) encoder and decoder. Tests: boolean encoding (true->y, false->n), scalar decoding (y->tvbool, ~->tvnull, 42->tvint), JSON-to-TOON conversion for objects, TOON-to-JSON for scalars, boolean round-trip through encoding/decoding, savings measurement for compressed output, and default options validation. Depends on std.test, std.str, core.optimiser.toon, and core.optimiser.toontypes.
