Integration test for shell accessibility features. Validates skip link presence and ordering, ARIA live regions (polite/assertive), sr-only CSS with clip rect, prefers-reduced-motion and prefers-contrast support, focus-visible outlines, keyboard navigation, focus trap/release/save/restore utilities, route announcements, and skip-to-main handler. Depends on browser.shell, loke.platform.a11y.*, std.str, shared.log.
