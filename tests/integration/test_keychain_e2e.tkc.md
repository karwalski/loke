End-to-end integration tests for the OS keychain storage layer. Tests: setting an API key, retrieving a stored API key, haskey existence check, deletekey removal, masking keys for display (last 4 chars visible), setkey/getkey round-trip, overwriting an existing key, and API key account prefix convention. Includes cleanup of test keys. X8.7: every call goes to a throwaway keychain file the test creates under its own throwaway HOME (std.keychain.create/use) and destroys at the end, never the user's login keychain; it stops before its first keychain call if the keychain cannot be created or selected. Depends on std.test, std.str, std.keychain, std, and core.storage.keychain.
