End-to-end integration tests for the OS keychain storage layer. Tests: setting an API key, retrieving a stored API key, haskey existence check, deletekey removal, masking keys for display (last 4 chars visible), setkey/getkey round-trip, overwriting an existing key, and API key account prefix convention. Includes cleanup of test keys. Depends on std.test, std.str, and core.storage.keychain.
