Exo cluster integration via REST API. Provides health checks, model listing, text generation (chat completions), and cluster topology queries against a local Exo instance (default 127.0.0.1:52415). Exports exoconfig, exomodel, and exoresult types, plus functions for health, listmodels, generate, clusterstatus, and JSON serialisation. Maintains GPL-3.0 licence boundary by using only REST. Depends on std.str, std.log, std.json, and std.http.
