Native inference engine for local model execution via ooke bindings. Defines nativeconfig (model path, threads, GPU layers, context length, seed), generateopts (temperature, top-p, max tokens, stop sequences), and generateresult types. Exports functions to create default configs, check if a model is loaded, load/unload models, run generation, and serialise results to JSON. Binding to llama.cpp is pending ooke readiness. Depends on std.str, std.log, and std.json.
