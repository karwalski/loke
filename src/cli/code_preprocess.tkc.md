Code preprocessing and secret scrubbing for CLI code-context requests. Detects programming languages by file extension, finds proprietary markers (PROPRIETARY, CONFIDENTIAL, copyright headers, opaque tokens), identifies sensitive config files (.env, .yaml, credentials), scrubs secrets (base64, API keys, hex hashes) with redaction placeholders, and profiles a codebase by file count, lines, and languages. Exports codeprofile and scrubresult types. Depends on std.string and std.log.
