CLI proxy mode that intercepts LLM API traffic through the loke privacy pipeline. Configures upstream targets (OpenAI, Anthropic) with a local listen port (11431), tracks request statistics (intercepted count, PII detected, tokens saved), renders a live terminal indicator showing current PII count and sensitivity, and prints session summaries. Exports proxyconfig, proxystats, and indicatorstate types. Depends on std.string and std.log.
