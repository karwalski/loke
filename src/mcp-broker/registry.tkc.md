MCP server registry tracking connection state and available tools. Manages a list of serverstate entries (config, status, tools, error, call count) and provides register, setstatus, settools, listservers, getserver, and listtools (with server-prefixed tool names). Exports tooldef, serverstate, and brokerstate types, plus JSON serialisation. Depends on std.string, std.log, and loke.mcpbroker.config.
