MCP broker core that initialises server connections and dispatches tool calls. Connects to registered MCP servers via stdio, SSE, or HTTP transports, enforces tool allow/deny lists, applies the privacy pipeline to tool arguments and responses, and logs audit trails. Exports toolcall and brokerresult types, plus init, dispatch, listalltools, serverstatusjson, and disableserver. Depends on std.string, std.log, loke.mcpbroker.config, loke.mcpbroker.registry, loke.mcpbroker.transport, and loke.core.privacypipeline.
