Temporal knowledge graph for the memory palace. Stores entity nodes and typed relations with validity intervals, supports fact queries filtered by subject, predicate, and point-in-time, detects contradictions where overlapping relations assert different targets, and can export the graph as Graphviz DOT. Exports entitynode, relation, factquery, and knowledgegraph types, plus newgraph, addnode, addrelation, queryfacts, detectcontradictions, visualisedot, and JSON serialisation. Depends on std.string, std.log, and std.json.
