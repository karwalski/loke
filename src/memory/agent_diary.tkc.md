Agent diary for recording and recalling agent run history within the memory palace. Stores per-agent diary entries capturing run id, summary, result, token usage, cost, duration, and user feedback. Supports retrieving recent entries, building startup context strings for agent re-prompting, compressing old entries via AAAK, recording post-hoc feedback, and serialising entries to JSON. Exports diaryentry, diary, and diarystore types. Depends on std.string, std.log, and std.json.
