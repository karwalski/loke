Unit tests for the browser UI component library. Covers button (variants, sizes, disabled/loading states, styles), input (labels, errors, hints, checkboxes), modal (role, aria attributes, close button), card (header/body/footer, interactive mode), form validation (required, min/max length, email, multi-rule field validation), and table (wrapper, columns, sorting, rows, styles). Depends on browser.components.button, input, modal, card, form, and table.
