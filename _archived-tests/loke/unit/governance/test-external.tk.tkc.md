Comprehensive unit tests for the external integration module (core.governance.external). Covers all integration presets (PagerDuty, Datadog, Grafana, Splunk, Elastic, Slack, Teams, OpsGenie, ServiceNow, generic webhook), payload formatting, event matching (exact, wildcard, audit.all), auth methods (bearer token, API key header, none), and config JSON serialisation. Depends on core.governance.external, std.str, and std.test.
