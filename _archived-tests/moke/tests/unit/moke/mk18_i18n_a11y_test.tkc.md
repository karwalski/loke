Integration tests for MK18 epic: validates all moke.* i18n keys exist in en.json locale, runs automated accessibility audits (landmarks, skip links, ARIA labels, form labels) against each moke page (index, chat, dashboard, upload, insight, settings, confirm, presentation), and verifies en-AU/en-US locale variants with correct spelling. Depends on loke.platform.a11y.testing, loke.platform.i18n.translator, std.str, std.log.
